# 코니 & 브라운 러브 런 💕

LINE FRIENDS 브라운과 코니가 나오는 팬메이드 HTML5 러닝 게임입니다. 이미지 파일 없이 **캐릭터를 모두 코드(벡터)로 그려서** 아무리 확대해도 깨지지 않고, 팔·다리·눈·입이 따로 움직입니다.

## 디자인
- 배경은 **Three.js 3D 공원**(단풍나무, 주황 울타리, 청록 줄무늬 집, 랜턴, 분홍 노을 하늘, 개울, 부드러운 그림자)이고, 캐릭터·하트·장애물은 그 위의 2D 레이어에서 그립니다(2.5D).
- 스테이지마다 하늘색·나무색·조명이 바뀝니다 (야시장·별똥별 밤은 랜턴 조명, 겨울은 눈 덮인 침엽수).
- UI는 흰 카드 + 짙은 초록 버튼 스타일.
- three.js는 CDN에서 불러오므로 **인터넷이 없으면 자동으로 2D 배경**으로 바뀝니다.

## 실행
- `index.html` 더블클릭
- 또는 이 폴더에서 `python -m http.server 8123` 실행 후 http://localhost:8123 접속

## 설정
- **누가 누구에게?** 코니→브라운 또는 브라운→코니 중에서 고릅니다. 대사와 엔딩도 선택에 맞게 바뀝니다.
- **난이도** 쉬움 / 보통 / 어려움 / 지옥. 쉬움은 속도 78%·가장 쉬운 장애물만·목숨 +2·하트 목표 25%·판정 넉넉. 나머지는 속도, 장애물 밀도, 하트 목표(50/60/70%), 미니게임 판정이 달라집니다.

## 조작
| 동작 | PC | 터치 |
|---|---|---|
| 점프 / 2단 점프(공중회전) | Space · ↑ (길게 누르면 높이) | 오른쪽 아래 버튼 / 화면 터치 |
| 슬라이드 (공중에서는 급강하) | ↓ · S | 왼쪽 아래 버튼 |
| 하트 던지기 (벌·공·구름 파괴) | X | 하트 버튼 |
| 일시정지 | Esc · P | 오른쪽 위 버튼 |

## 골인 장면
- 하트를 목표치 이상 전하면 둘이 서로 달려와 꼬옥 안고, 안은 채 뱅글뱅글 돌며 하트와 색종이가 터집니다. 마지막에는 나란히 붙어 서서 고개를 기울이고 두 손을 모은 채 활짝 웃는 장면(둘레에 하트)으로 마무리해요. 설정 화면의 카드에서도 같은 장면(손 흔들기 → 달려감 → 포옹 → 빙글빙글)이 반복됩니다.

## 달리기 연출
- 몸을 앞으로 기울이고 얼굴이 진행 방향을 향한 채 성큼성큼, 결연한 표정으로 달려요.
- 빨라질수록 바람 줄무늬·잔상·넓어지는 시야(배경이 휙휙), 25/50/75/88% 지점마다 속도 상승과 안내 문구, 마지막 스퍼트.
- 오른쪽 가장자리에 다가오는 위험 경고(▲), 아슬아슬하게 피하면 보너스, 맞으면 잠깐 멈칫하며 화면이 붉게, 목숨 1개면 심장 박동.

## 규칙 (쉽지 않아요!)
- 구덩이, 높은 담장, 숙여야 하는 현수막, 굴러오는 공, 날아다니는 방해꾼, 떨어지는 고드름·별똥별, 움직이는 발판
- 목숨 3개. 결승선에서 **하트를 목표치 이상** 모으지 못하면 실패
- 연속으로 하트를 먹으면 콤보 배율(최대 x5), 별 1~3개와 S/A/B/C 랭크

## 스테이지 (10개)
꽃길 → 공원(뽀뽀) → 놀이공원(하트 받기) → 러브 짐(리듬 운동) → 쿠킹(기억력 요리) → 비 오는 날(대화) → 겨울 마을(하트 받기) → 야시장(낚시) → 별똥별 밤(뽀뽀) → 고백 대작전 → 엔딩(사랑 게이지에 따라 3종)

## 파일 구조

- `js/run.js` 달리기, `js/mini.js` 미니게임, `js/screens.js` 메뉴·지도·결과·엔딩

- `dev/gallery.html` 캐릭터 동작 미리보기
